## 1. Product Search

### 1. Search Product by Name (ProductSearchFromName)

- **Endpoint description**: Search 1688 platform for related products by name.
- **Requests consumed**: 2
- **Supported domains**: 601(1688)
- **Request parameters**:
  | Parameter | Type | Required | Description |
  |------|------|------|------|
  | Name | String | Yes | The product name to search |
  | Page | Integer | No | Paginated query, at most 100 products per page. Default 1, representing page 1 (all result pagination starts from 1, not 0) |

- **Typical uses**:
  - **Sourcing cost analysis**: Input a hot-selling product name on Amazon, query the corresponding supplier's wholesale price on 1688, and calculate the profit margin.
  - **Supplier filtering**: Filter and compare quotes from different suppliers using the seller info in the result. The price of the same product from different suppliers can vary widely.
  - **Product selection verification**: Combined with sales data from Amazon/TikTok, confirm whether a product has sufficient supply chain support on 1688.
  - **Competitor price monitoring**: Periodically query 1688 price changes for similar products to track supply chain cost fluctuations.

- **Usage example**:
  ```bash
  sorftime api ProductSearchFromName '{"Name": "transparent acrylic double-sided tape"}' --domain 601
  ```

- **Response data**:
  - `Title`: Product title, e.g. Transparent Acrylic Double-Sided Tape Strong Foam Double-Sided Tape Sponge Tape Round Removable Ornament Nano No-Trace Adhesive.
  - `Photo`: This product's main image, URL format. E.g. `https://cbu01.alicdn.com/img/ibank/O1CN01HrY28j1LS4eMNQV1G_!!3086091297-0-cib.jpg`.
  - `Url`: Product link. E.g. `https://detail.1688.com/offer/789542752062.html?sk=order`.
  - `Price`: Product selling price, e.g. 0.01.
  - `ProductId`: Product ID, e.g. 789542752062.
  - `StoreName`: Store name, e.g. Dongguan Junchuang Rubber & Plastic Products Co., Ltd.
  - `ServiceScore`: Composite service score, e.g. 4.5.
  - `ServiceScoreDetail`: Service score details, JSON format, e.g. `[{"title":"Sourcing Consultation","score":4},{"title":"Logistics Timeliness","score":3.29},{"title":"Dispute Resolution","score":5},{"title":"Quality Experience","score":5},{"title":"Return/Exchange Experience","score":5}]`.
  - `OnlineDate`: Listing time, format: yyyy-MM-dd, e.g. 2026-06-22.
  - `SalesOf30d`: Last 30-day sales count, e.g. 30.
  - `WholesalePriceRange`: Wholesale price range, JSON format, e.g. `[{"price":1.5,"purchaseQuantity":"≥ 200"},{"price":1.2,"purchaseQuantity":"≥ 500"}]`.
  - `RepurchaseRate`: Repurchase rate, unit: %. E.g. 65.56.
  - `ShippingOrigin`: Shipping origin, e.g. Guangzhou.
  - `ShippingTime`: Shipping timeliness, e.g. 24-hour shipping.
  - `SellerIdentities`: Seller identity tags, e.g. `["Super Factory", "Power Seller"]`.
  - `OfferIdentities`: Product tags, e.g. `["Strictly Selected"]`.
  - `ReviewCount`: Review count, e.g. 106.
  - `Score`: Star rating, e.g. 4.6.
  - `SkuCount`: SKU count, e.g. 8.
  - `MinOrderQuantity`: Minimum order quantity (taken from the first `purchaseQuantity` in `WholesalePriceRange`), e.g. 2.
  - `IsDropShipping`: Whether drop-shipping is supported, e.g. true.
  - `StockCount`: Stock count, e.g. 985897203.

### 3. Product Search (ProductSearch)

- **Endpoint description**: Multi-dimensional product search.
- **Requests consumed**: 5
- **Supported domains**: 601(1688)
- **Request parameters**:
  | Parameter | Type | Required | Description |
  |------|------|------|------|
  | Page | Integer | No | Paginated query, at most 100 products per page. Default 1, representing page 1 (all result pagination starts from 1, not 0). E.g. 1 |
  | ProductId | String | No | Optional. If specified: query similar products by ProductId (note: not limited to this ProductId; if you need this product, call the ProductRequest endpoint). E.g. B0CVM8TXHP |
  | NodeId | String | No | Optional. If specified: query by category (not limited to sub-categories). E.g. 7073960011 |
  | SupplierName | String | No | Optional. If specified: fuzzy-match products by supplier name. E.g. Yiwu XXX Accessories Factory |
  | SupplierType | Integer | No | Optional. If specified: filter by supplier type, single-select. 1 = Power Seller, 2 = Super Factory. E.g. 1 |
  | SupplierMemberType | Integer | No | Optional. If specified: filter by supplier member type, single-select. 1 = Deep-certified, 2 = Not deep-certified. E.g. 1 |
  | ServiceScoreMin | Number | No | Optional. If specified: limit minimum composite service score (val >= set value) when querying products. E.g. 4.5 |
  | ServiceScoreMax | Number | No | Optional. If specified: limit maximum composite service score (val <= set value) when querying products. E.g. 5.0 |
  | OnlineDateRangeMin | String | No | Optional. If specified: limit listing date start time when querying products, date format yyyy-MM-dd. E.g. 2025-01-01 |
  | OnlineDateRangeMax | String | No | Optional. If specified: limit listing date end time when querying products, date format yyyy-MM-dd. E.g. 2026-01-01 |
  | DropshippingPriceRangeMin | Number | No | Optional. If specified: limit minimum selling price (val >= set value) when querying products. E.g. 20.00 |
  | DropshippingPriceRangeMax | Number | No | Optional. If specified: limit maximum selling price (val <= set value) when querying products. E.g. 50.00 |
  | CumulativeSaleCountMin | Integer | No | Optional. If specified: limit minimum cumulative sales (val >= set value) when querying products. E.g. 100 |
  | CumulativeSaleCountMax | Integer | No | Optional. If specified: limit maximum cumulative sales (val <= set value) when querying products. E.g. 5000 |

  | Recent30DaySaleMax | Integer | No | Optional. If specified: limit maximum last-30-day sales count (val <= set value) when querying products. E.g. 2000 |
  | RepurchaseRateMin | Number | No | Optional. If specified: limit minimum repurchase rate (val >= set value) when querying products. E.g. 0.05 |
  | RepurchaseRateMax | Number | No | Optional. If specified: limit maximum repurchase rate (val <= set value) when querying products. E.g. 0.30 |

  | SkuCountMax | Integer | No | Optional. If specified: limit maximum SKU count (val <= set value) when querying products. E.g. 20 |
  | StockCountMin | Integer | No | Optional. If specified: limit minimum stock count (val >= set value) when querying products. E.g. 100 |
  | StockCountMax | Integer | No | Optional. If specified: limit maximum stock count (val <= set value) when querying products. E.g. 10000 |

### 5. Product Variant Data (ProductVariations)

- **Endpoint description**: Query the variant information of a product that has been updated in the last 15 days.
- **Requests consumed**: 1
- **Supported domains**: 601(1688)
- **Request parameters**:
  | Parameter | Type | Required | Description |
  |------|------|------|------|
  | ProductId | String | Yes | The product ID to query. E.g. 789542752062 |

- **Usage example**:
  ```bash
  sorftime api ProductVariations '{"ProductId": "789542752062"}' --domain 601
  ```

- **Response data**:
  - `Data`: Variant product information list, each element includes the following fields, e.g. `[{"SkuId":"SKU001","SkuName":"White-M","Price":"10.00","OfferPrice":"12.00","Stock":"100","Width":"10","Length":"20","Height":"5","Weight":"0.5","PkgSizeSource":"manual"}]`.
  - `Data.SkuId`: Variant product ID.
  - `Data.SkuName`: Variant name.
  - `Data.Price`: Wholesale price.
  - `Data.OfferPrice`: Drop-shipping price.
  - `Data.Stock`: Stock.
  - `Data.Width`: Width.
  - `Data.Length`: Length.
  - `Data.Height`: Height.
  - `Data.Weight`: Weight.
  - `Data.PkgSizeSource`: Source of package size and weight.

## 3. Credits and Quota

### 6. Query This Month's Remaining Credits (CoinQuery)

- **Endpoint description**: Query remaining credits.
- **Requests consumed**: 0
- **Supported domains**: 601(1688)
- **Note**:
  - The credit balance is **not differentiated by site or platform**. The credits obtained by querying through any site or platform is the total credit balance.
- **Request parameters**: none
- **Usage example**:
  ```bash
  sorftime api CoinQuery '' --domain 601
  ```
- **Response data**:
  - `Coin`: This month's remaining credits.

### 7. Query Credit Usage Details (CoinStream)

- **Endpoint description**: Query the credit usage details on the queried site.
- **Requests consumed**: 0
- **Supported domains**: 601(1688)
- **Request parameters**:
  | Parameter | Type | Required | Description |
  |------|------|------|------|
  | Querydate | Array | No | A 2-element array; element 0 is the query start time, element 1 is the query end time. Format yyyy-MM-dd. Queries by week, default the most recent 6 months, max range is the most recent 12 months |
  | PageIndex | Integer | No | Query result page index, default page 1 |
  | PageSize | Integer | No | Items per page, min 20, default 20, max 200 |

- **Usage example**:
  ```bash
  sorftime api CoinStream '{"Querydate": ["2025-01-01", "2025-06-30"], "PageIndex": 1, "PageSize": 50}' --domain 601
  ```

- **Response data**:
  - `Data`: Credit consumption details. Example: `[6, 202010010300, -1000, 190000, 6, 202010010400, -1010, 180000, 6, 202010010530, -1050, 170000, .....]`. `array index % 4 = 0` is the task type: 1=keyword monitoring, 3=hijacker & stock monitoring, 9=ASIN real-time collection, 10=review real-time collection, 12=Best Seller list monitoring, 15=ASIN subscription update, 27=image-search similar product. `array index % 4 = 1` is the date (e.g. 20201001), format yyyyMMddHHmm. `array index % 4 = 2` is credits spent. `array index % 4 = 3` is credits remaining.

### 8. Query Monthly Request Usage Details (RequestStreamMonth)

- **Endpoint description**: Query remaining request count, and the usage of purchased request packs.
- **Requests consumed**: 0
- **Supported domains**: 601(1688)
- **Note**:
  - Request queries **are not differentiated by site**. The values obtained by querying through any site is the total request balance.
  - For detailed call history, please contact us. For user privacy, we only retain the last 3 days of call records.
- **Request parameters**: none
- **Usage example**:
  ```bash
  sorftime api RequestStreamMonth '' --domain 601
  ```
- **Response data**:
  - `Purchase`: Purchase details. Value description: `[["20241001", // purchase time "420000", // requests obtained "0", // current remaining requests "20240930" // expiration time], ...]`.
  - `Consume`: Monthly consumption details. Value description: `[["202411", // month "1000" // requests used this month], ["202410", // month "1000" // requests used this month]]`.

## Notes

- **Sole site**: The 1688 platform only supports `domain=601`; there is no other site variant. All calls must pass `--domain 601`.
- **Credits and Request balance**: The balances obtained by querying `CoinQuery` and `RequestStreamMonth` are **global** values, not differentiated by site or platform.
- **Request cost tiers**: 1688 endpoint request costs range from 0 to 5:
  - 0 cost: CoinQuery, CoinStream, RequestStreamMonth (balance / detail queries)
  - 1 cost: ProductRequest, ProductVariations (single-product query)
  - 2 costs: ProductSearchFromName, ProductSearchFromImage (search by name / image)
  - 5 costs: CategoryTree, ProductSearch (category tree / multi-dimensional search)
- **Large data response**: The `CategoryTree` endpoint returns approx. 10MB+ of data; it is recommended to set a long request timeout in the CLI client.
- **Multi-dimensional filtering**: `ProductSearch` supports 20+ filter condition combinations, suitable for fine-grained product selection; `ProductSearchFromName` only supports fuzzy name-keyword search.
- **Image search**: `ProductSearchFromImage` requires a network image URL (≤1MB), used for finding the same product's source via image.
- **JSON String fields**: `ServiceScoreDetail` and `WholesalePriceRange` fields are JSON strings (not yet-parsed objects) in the response; you need to `JSON.parse` them before use.

## Best Practices

- **Sourcing cost analysis**: First use the Amazon/TikTok/Walmart platform endpoint to get the product name, then use `ProductSearchFromName` on 1688 to query the corresponding wholesale price, and use the `WholesalePriceRange` field to judge the price range at different order quantities.
- **Supplier filtering**: Filter quality suppliers through `ProductSearch`'s `SupplierType` (Power Seller / Super Factory) and `SupplierMemberType` (Deep-certified), then use `ProductRequest` to view full details.
- **Fine-grained product selection**: Use the composite filter conditions of `ProductSearch` (e.g. `Recent30DaySaleMin` + `RepurchaseRateMin` + `IsDropShipping`) to locate high-quality drop-shipping suppliers in one step.
- **Image reverse-sourcing**: First use an Amazon product's main image URL to call `ProductSearchFromImage`, and quickly find the same product's source on 1688.
- **Combined product selection + details + variants**: First use `ProductSearch` or `ProductSearchFromName` to identify a product list, then call `ProductRequest` for the `ProductId` of interest to view details, and further use `ProductVariations` to get variant (SKU) price, stock, dimensions, and weight data.
